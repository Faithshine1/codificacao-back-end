## Projeto Node.js
Projeto desenvolvido nas aulas de Node.js para aprendizado de desenvolvimento back-end.
## systemLog
Na Aula 2, foi adicionado o System Log, responsável por registrar informações e eventos importantes durante a execução da aplicação, facilitando o acompanhamento e a identificação de erros.

Com essa implementação, é possível registrar eventos do sistema, como:

Inicialização da aplicação;
Acessos e requisições;
Informações importantes durante a execução;
Erros e possíveis falhas.

Este projeto está sendo desenvolvido de forma incremental durante as aulas, permitindo acompanhar a evolução da aplicação e aplicar na prática os conceitos aprendidos em Node.js.
